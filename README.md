# ai-sana

Финальный проект III этапа AI-SANA (Программа 2): MVP для реальной отраслевой задачи, слайды по 12 этапам и видеопитч.

Сейчас здесь только ресерч и план. Продукт не начат.

Важно: в сдаче запрещено использовать ИИ для создания контента. Эти файлы — рабочие заметки, собранные с помощью ИИ; тексты слайдов и видео команда пишет сама.
